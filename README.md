*Ajoute des items custom au loot du brossage des blocs suspects.*

## Présentation

Ajoute des items custom au loot du brossage des blocs suspects.

Utilisé sur : **Opale**.

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/shcustombrush` | — | Ajouter des items custom au loot de brossage. | — |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shcustombrush.add` | Permet d'ajouter des items à la table de loot | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`). Cliquez sur un fichier pour l'ouvrir :

<pre>
plugins/SHCustomBrush/
└── <a href="src/main/resources/config.yml">config.yml</a>
</pre>

## Compilation

Java 25 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
